# Art Ross Tax Prep Platform: Compliance & Integration One-Pager

## Overview
A modern, full-stack tax preparation platform with robust compliance, audit, and security features. Built with FastAPI (Python) backend and React (Vite + TypeScript) frontend, supporting role-based dashboards, audit logging, and automated compliance checks.

---

## Key Features
- **Backend:** FastAPI, SQLAlchemy ORM, modular routers, OpenTelemetry, audit logging, CADE2/EWS compliance logic, SQLite/Cloudflare D1 DB.
- **Frontend:** React (Vite), role-based dashboards, KIMBIE DaA+ theme, API integration for all widgets, compliance UI.
- **Compliance:** RBAC, JWT auth, audit logging, CADE2/EWS checks, IRS/state hooks, end-to-end encryption, CI/CD security.
- **Seeding:** Automated schema migration and demo/live data seeding for users, tenants, tax profiles, and credit reports.

---

## Compliance & Security Highlights
- **RBAC & Auth:** All sensitive endpoints require JWT Bearer token; role-based access enforced.
- **Audit Logging:** All sensitive actions logged with "AUDIT" tag; logs exportable for review.
- **Data Privacy:** No data sold/shared except as required by law; user data export/deletion on request.
- **CI/CD:** Automated dependency, secret, and vulnerability scanning; deployment blocked on compliance failure.
- **Encryption:** All secrets managed via secure env vars; end-to-end encryption for sensitive data.
